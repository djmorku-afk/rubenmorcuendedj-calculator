# 🎵 DJ Earnings Calculator

Una **web app moderna** para que DJs calculen sus ingresos potenciales mensuales de forma fácil y rápida.

## ✨ Características

- 💰 **Cálculo automático** de ingresos brutos, gastos y beneficio neto
- 📊 **Panel de resultados** intuitivo y en tiempo real
- ⚙️ **Panel de administración** para personalizar todos los conceptos y variables
- 💾 **Guardado local** - Los datos se guardan en tu navegador
- 📋 **Exportar resultados** - Copia y descarga tus cálculos
- 📱 **Totalmente responsivo** - Funciona en móvil, tablet y desktop
- 🎨 **Diseño moderno** - Interfaz oscura profesional

## 🚀 Inicio Rápido

### Opción 1: Abrir directamente
Descarga los archivos y abre `index.html` en tu navegador.

### Opción 2: GitHub Pages
1. Ve a **Settings** → **Pages**
2. Selecciona la rama `main`
3. ¡Tu app estará en `https://tu-usuario.github.io/rubenmorcuendedj-calculator`

### Opción 3: Vercel
1. Conecta el repo a [Vercel](https://vercel.com)
2. ¡Deployment automático!

## 🧮 Fórmulas

- **Ingresos Brutos** = (Eventos × Caché) × Multiplicador
- **Gastos** = (Eventos × Gastos Fijos) + (Brutos × % Impuesto)
- **Beneficio Neto** = Ingresos Brutos - Gastos
