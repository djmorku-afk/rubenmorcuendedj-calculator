# 😂 Random Joke Generator

A fun web app that generates random jokes from an external API with multiple categories and filtering options.

## ✨ Features

- 🎲 Generate random jokes from JokeAPI
- 🏷️ Multiple categories (General, Programming, Knock-Knock)
- 🔒 Safe mode filtering
- 💾 Save favorite jokes locally
- 📤 Share jokes to clipboard
- 📊 Statistics tracking
- ⚙️ Customizable settings
- 🎨 Multiple themes
- 📱 Fully responsive design

## 🚀 Quick Start

### Option 1: GitHub Pages
1. Go to: https://github.com/djmorku-afk/rubenmorcuendedj-calculator
2. Settings → Pages → Enable Pages
3. Visit: `https://djmorku-afk.github.io/rubenmorcuendedj-calculator/jokes/`

### Option 2: Local
Just open `jokes/index.html` in your browser!

## 📋 Features Explained

### Categories
- **Any**: Mix of all categories
- **General**: Standard jokes
- **Programming**: Tech/coding jokes
- **Knock-Knock**: Classic knock-knock jokes

### Joke Types
- **Any**: Single jokes or two-part jokes
- **Single**: Complete joke in one line
- **Two-Part**: Setup and punchline format

### Safe Mode
When enabled, filters out jokes with offensive content

### Favorites System
- Click the heart button to save jokes
- All favorites stored locally in your browser
- View and manage favorites in the "My Favorites" section
- Remove individual favorites or clear all at once

### Sharing
- Copy joke to clipboard with one click
- Share with friends via messaging apps
- Includes source attribution

## ⚙️ Customization

Click **⚙️ Settings** to:
- Configure API URL
- Adjust cache limit
- Set custom colors
- Enable auto-play
- Configure auto-play delay

## 📊 Statistics

- **Jokes Loaded**: Total jokes fetched during session
- **Favorites**: Number of saved favorite jokes

## 🔌 API Used

**JokeAPI v2**
- URL: https://v2.jokeapi.dev/joke
- Documentation: https://jokeapi.dev
- Supports multiple categories and filtering
- No authentication required
- Rate limit friendly

## 💾 Data Storage

All data stored locally:
- Favorite jokes
- Settings preferences
- Color customization
- User preferences

## 🌐 Compatibility

✅ Chrome, Firefox, Safari, Edge
✅ Mobile, Tablet, Desktop
✅ Works offline (favorites only)
