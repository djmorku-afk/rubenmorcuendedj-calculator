# 🕐 Digital Clock - Multiple Time Zones

A modern web app that displays the current time in different time zones around the world.

## ✨ Features

- 🌍 Display time in multiple time zones simultaneously
- ⏰ Real-time clock updates every second
- 📅 Show/hide date information
- 🎨 Multiple themes (Dark, Light, Neon)
- ⚙️ Customize colors and display options
- ➕ Add custom time zones easily
- 💾 Save your preferences locally
- 📱 Fully responsive design

## 🚀 Quick Start

### Option 1: GitHub Pages
1. Go to your repo: https://github.com/djmorku-afk/rubenmorcuendedj-calculator
2. Navigate to **Settings** → **Pages**
3. Enable Pages on branch `main`
4. Visit: `https://djmorku-afk.github.io/rubenmorcuendedj-calculator/clock/`

### Option 2: Local
Just open `clock/index.html` in your browser!

## 📋 Features Explained

### Time Formats
- 24-Hour Format: `14:30:45`
- 12-Hour Format: `2:30:45 PM`

### Themes
- **Dark**: Professional dark interface with cyan accents
- **Light**: Clean white background for daytime use
- **Neon**: Retro green-on-black hacker style

### Custom Time Zones
Add any time zone with UTC offset:
- Name: Your city/region name
- Offset: UTC-12:00 to UTC+12:00
- Includes half-hour offsets (India, Australia, etc.)

### Display Options
- Show/hide seconds
- Show/hide date
- Show/hide UTC offset

## 🎨 Customization

Click **⚙️ Settings** to:
- Change text and background colors
- Toggle display elements
- Save your preferences
